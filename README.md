# Analytics & Management Hub

A high-performance, enterprise-grade admin dashboard designed for real-time data visualization and streamlined ecommerce operations. This project transforms complex data into actionable business intelligence through a modular, scalable architecture.

## 🚀 Business Value

- **Actionable Insights:** Real-time data visualization allows stakeholders to monitor KPIs, revenue trends, and customer behavior at a glance.
- **Operational Efficiency:** Centralized management for products, orders, and customers reduces administrative overhead and improves response times.
- **Scalable Architecture:** Built with a modular component design, the platform is easily extensible to support additional features and integrations.
- **Data-Driven Decisions:** Integrated CSV export and search/filtering capabilities empower teams to perform deep-dives into operational data.

## ✨ Key Features

- **Real-time Data Visualization:** Interactive charts using Chart.js for tracking revenue, sales trends, and categorical distributions.
- **Responsive Grid Layout:** A fluid, adaptive interface that provides a seamless experience across desktop, tablet, and mobile devices.
- **Modular Component Design:** Atomic design principles applied to UI components (Cards, Tables, Modals) for maximum reusability.
- **Advanced Data Management:**
  - **Dynamic Tables:** Comprehensive views for Orders, Customers, and Transactions.
  - **Search & Filter:** Real-time filtering for deep data exploration.
  - **Export Capabilities:** One-click CSV export for offline analysis.
- **User Management & Notifications:** Integrated modules for managing system users and real-time operational alerts.

## 🛠️ Tech Stack

- **Frontend:** React 18 with Vite for lightning-fast development and optimized production builds.
- **Language:** TypeScript (Type-safe interfaces for data models).
- **Styling:** Tailwind CSS for a modern, utility-first design system.
- **Charts:** Chart.js & React-Chartjs-2 for high-performance rendering.
- **Navigation:** React Router 6 for seamless client-side routing.

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Berkayozgun/ecommerce-dashboard-v2.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start development server:**
   ```bash
   npm run dev
   ```
